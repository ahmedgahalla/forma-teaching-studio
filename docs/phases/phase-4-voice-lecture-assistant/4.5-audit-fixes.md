## Decisions and documentation

Exploration closes tooth study rather than refusing the command: a professor asking to explore an arrangement returns to its full mouth, and the prepared-case return path retains the pre-study display/camera. This is documented in [Tooth study](../../TOOTH_STUDY.md).

The terminal dental-parser no-match now uses `UnrecognizedCommandError` instead of a generic error, making glossary fallback depend on a precise outcome. Exact definition-close phrases with an open definition remain a dedicated control before Try Mode's broad `close` clarification; no definition lookup runs there. Without an open definition, existing handling wins. Case preflight advances only the synthetic/root capabilities used by the permitted authored visual sequences; it creates no temporary geometry and does not widen the single prepared-case command boundary.

[ADR 004](../../decisions/004-hands-free-voice.md), [Voice Classroom](../../VOICE_CLASSROOM.md), Settings copy and the [Professor guide](../../PROFESSOR_GUIDE.md) describe full wake phrases, local-only aliases and hidden-tab pausing. Lessons 17–19 cover grammar ownership, silence backoff and close routing; lesson 14 is incremented for camera findings 4/5 and lesson 16 for sequential model-capability preflight. AGENTS promotion is deferred because this task explicitly prohibits editing that file. Phase 4 review inbox files retain their open manual/educator acceptance items and link the addressed audit fixes.
