# 2.5 — Backend modules

**What was done** (commit `e5beb75`; the legacy route itself was removed in 2.1c): `backend/main.py` (1,079 lines) → **148 lines** plus six focused modules — `core.py` (StrictModel, provider error mapping), `commands.py` (dental command models + `resolve_targets`), `teaching_schema.py`, `teaching_prompts.py`, `teaching_source.py`, `teaching_validation.py`. `scene_analysis.py` was already a router and `phone_bridge.py` already a separate app, so "routers" resolves to module extraction around the existing FastAPI app.

**Decision (ADR 003):** `main.py` keeps the app object, `/health`, the provider-call functions and the teaching route, and re-exports every moved name — the 470-test suite monkeypatches `main.<name>` seams, and preserving them kept the split behavior-identical without touching a single test.

**Evidence:** backend suite 470/470 after the split (the interim NameError cascade during extraction was fully test-driven down to green).

**Skipped:** `mechanics.py` (577) stays whole — a Pydantic model set plus its mirrored text-grammar helpers that the frontend fixtures track one-to-one; allowlist-justified.
