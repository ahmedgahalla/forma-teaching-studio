# 2.2 — Studio split

**What was done** (commits `b0f13bf`, `4e72811`, `54c90ee`, `ee5431e`): Studio.tsx went from **5,123 lines to 1,011** with zero behavior change, in four gated sub-slices.

- **a+b — constants, types, state hooks:** `case/constants.ts`, `case/ui.tsx` (Dialog, Toggle), `case/types.ts` (incl. the previously inline `ClassroomSnapshot`), and `case/state.ts` with sixteen feature hooks (useMechanicsState, useCaseScenario, useModelState, useDisplayState, useSelectionState, useStagePlayback, useMovementInputs, useCommandState, useLayoutState, useCaseFiles, useMeasureState, useLessonState, useAttachmentState, useManipulationTool, useCalibrationInputs, useServiceDraft) owning all ~70 useState plus the history `useReducer`. CaseStudio destructures them, so downstream code reads unchanged. Mutable refs stay component-local — the react-hooks immutability rule correctly treats hook returns as frozen.
- **c — JSX extraction:** CaseTopbar, CaseSidebar, CaseMain, CaseInspector and CaseDialogs receive the typed `CaseStudioApi` bundle. References were rewritten with a TypeScript-AST tool (expression positions only; shorthand-safe), never textually — one manual fix where a local `const tooth` shadowed the api field, and TS property-narrowing restored via local destructures where callbacks needed it.
- **d — sub-300 views:** CaseMain → WorkspaceHeading/ArchToolbar/Viewport/LectureOverlay/StageDock + a 140-line shell; CaseInspector → Scenario/Move/Braces/Analysis/History tabs + shell; CaseDialogs → Library/Setup/Info groups + shell.
- **e — handler factories:** ten `create*` factories plus `preflight.ts` and `teaching-load-kinds.ts` (the dispatcher's arrangement/case family, split when the untracked-file gap in check:limits was found and fixed). Two-phase api assembly; adapter and tryPanelProps wired after assembly.

**Decisions:** ADR 003 (api-bundle seam, late-binding factories, CaseRefs container, file-scoped refs-rule note).

**Skipped:** per-view narrowed props (follow-up; the api seam is documented); converting `returnWorkspace` to state (a `canRestoreWorkspace` boolean crosses the render boundary instead).

**Evidence:** browser check after c and after e — all six baseline screens pixel-identical at 1600×900 (only playback-timing differs); typed bracket/wire commands, prepared-case play and the braces workflow exercised the extracted dispatchers. Suite 1,575/1,575 after every sub-slice.
