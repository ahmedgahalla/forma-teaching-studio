# 2.1 — Dead-code removal

**What was done.** Candidates were found with knip (a committed `knip.json` now gives it the correct entry points: the app, the worker, tests, and scripts) plus two knip passes (tests as entries / tests excluded), then **every candidate was verified by a read-only agent** before removal — 23 verification agents in one workflow: per-file export verification with dynamic-import awareness (the anatomy/audit scripts import `src/lib` modules dynamically, which import-greps miss), a four-pass dead-CSS analysis (literal, tokenizer, dynamic-construction enumeration, compiled-bundle cross-check), a commented-out-code sweep, and a dedicated legacy-endpoint assessment.

## Removed (commit 2.1a — frontend)

- `src/components/useSpeech.ts` — nothing imported it; live voice goes through `lib/push-to-talk`.
- `createSpeechController` in `src/lib/speech.ts` (~180 lines) — its only consumer was `useSpeech`; `speechConstructor` and the recognition types stay (used by `TeachingController` and `push-to-talk`). Its 22 controller tests went with it; one `speechConstructor` test remains.
- `exportSTL` in `src/lib/geometry.ts` — reachable only from its own test (per-stage export in `stage-export.ts` is the live path). Test removed with it.
- 27 `export` keywords dropped (values/types kept, all used internally): `AppliancePalette`(named)/`AppliancePaletteProps`, `WIRE_OPTIONS`, `TryPreviewCard`/`Props`, `TeachingCaseCard`, `TEACHING_ASSET_URL`/`TEACHING_METADATA_URL`, `toothName`, `parseMechanicsClause`, `TRY_COLLISION_LIMITATION`, 4 try-mode types, 8 mechanics types, `HistoryEntry`, `RootSection`, `CaseDemonstration`.
- Frontend suite: 1,599 → **1,575 tests** (24 removed with their dead code), all passing. The teaching-case audit was regenerated (the `CaseDemonstration` unexport changed `teaching-cases.ts` bytes — the hash test caught it, as designed).

- `studio-experience.css` (19), `try-mode.css` (7, `try-display-tools`), `lecture-view.css` (1 group rule).
- Browser check: all six baseline screens pixel-identical at 1600×900 after removal.

## Removed (commit 2.1c — backend legacy endpoint)

- `POST /api/interpret` route, `interpret_with_openai`, its `INSTRUCTIONS` prompt, and the `Interpretation` model (~95 lines of `backend/main.py`). Verified: no frontend caller (`src/` has only `/api/interpret-teaching`), the phone bridge never proxied it (and its 404 test still covers that).
- **Kept deliberately:** the whole `Command` model union, `InterpretRequest`, and `resolve_targets` — they are load-bearing for `/api/interpret-teaching` (`TeachingDental.command`, plan validation, target auditing).
- Tests: `test_main.py` rewritten — the resolve_targets edge-case coverage (group resolution, range/ambiguity rejection, amount-vs-ID disambiguation) is re-hosted directly against the helper; health + CORS kept; a new test pins the route as gone. `test_teaching.py`: legacy parametrize leg and the legacy-only reasoning test removed. Backend suite: 531 → **470 tests**, all passing.
- Docs updated in the same commit: `README.md` (two availability claims), `backend/README.md` (§ request/response reframed around the shared command model, data-flow trimmed), `docs/architecture/overview.md`.
