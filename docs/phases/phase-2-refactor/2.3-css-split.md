# 2.3 — CSS split

**What was done** (commit `a531f35`, repair in `018b5c1`): every stylesheet over 300 lines became an `@import` index over ordered partials — `src/app/globals.css` (4,573 lines) → `src/app/styles/` (20 partials); studio-experience (9), mechanics (6), try-mode (3), classroom-workspace (3) and lecture-console (2) → sibling `<name>.styles/` folders.

**Decision (ADR 003):** partials preserve the original rule order byte-for-byte instead of regrouping per component, because @import order = cascade order; regrouping risks specificity flips the demo cannot absorb. The indexes live where the old files did, so no import site changed.

**Files touched:** the six stylesheets + 43 partials; `src/app/layout.tsx` untouched.

**Skipped:** merging near-duplicate selector blocks across partials (visible now that the files are readable) — cleanup for a later pass, listed in the review inbox rather than risked here.

**Evidence:** full six-screen browser check after the globals split and again after the component splits — pixel-identical. One defect was introduced and caught: the splitter emitted the body-less Google-fonts `@import` without its semicolon (postcss `toString` omits it), Prettier then mangled the line, and `npm run build` failed — fixed in `018b5c1`; the gate's build step is the enforcement.
