## Request and outcome

The owner asked for the same diagram Claude placed beneath the model. This is the two-row dental chart (odontogram) in the authorized local Dentition Atlas source. Forma previously used simplified tooth silhouettes. It now uses Claude's exact crown/root path formulas and the bundled model's per-tooth dimensions.

1. Identify and port the original drawing data; verify all 32 source outputs against an independently captured source hash.
2. Adapt the chart layout and preserve existing selection; verify quadrant order, lower-tooth reflection, extraction spaces, optional wisdom positions and interaction boundaries.
3. Run the automated gate and record the remaining visual acceptance separately.

## Implementation

- `src/lib/atlas-tooth-diagram.ts` precomputes immutable crown/root drawings from the existing metadata. Incisors, canines, premolars and molars retain the source's distinct shapes and root depictions. No new model download or geometry change is required.
- `AtlasToothChart.tsx` renders the two arches in patient right-to-left order with equal quadrant halves. Lower drawings reflect vertically so opposing crowns face each other. Labels, proportional tooth widths, central dividers and R/L markers follow Claude's chart.
- `atlas-chart.css` supplies the compact responsive layout, source-style fine roots/filled crowns and Forma's existing theme/selection colors. The obsolete narrow-screen padding override in `atlas-workspace.css` was removed so it cannot replace the chart's mobile spacing.
- Only teeth present in the current case are buttons. Missing teeth retain blank proportional spaces; default cases remain 28 teeth. A case containing wisdom teeth can show the corresponding 32 positions without making absent teeth selectable.
- Native button labels and pressed state remain accessible. Clicking, Shift/Ctrl/Meta additive selection, hidden-arch reveal, locked titles, moved indicators and the existing scene interaction classifier are preserved. A short footer reports the selected tooth/count.

The chart remains under the Explore model in its existing location. Lecture/presenter visibility, mechanics, gum following, playback, saved state and the source producer workspace are unchanged. This is an illustrative atlas diagram, not patient-specific anatomy. The subsequently observed producer model export is outside this diagram request; the paired 10:33 model snapshot from 3.22 remains bundled.
