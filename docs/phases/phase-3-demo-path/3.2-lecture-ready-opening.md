# 3.2 — Lecture-ready opening

**Status:** implemented; awaiting audit · **Branch:** `ahmed/phase-3-lecture-opening` · **PR:** pending

## Goal and scope

Make the first screen a calm model workspace. The owner authorized Phase 3 implementation on 26 September and asked to reduce the overwhelming interface. This implements proposal PR #12's 3.2 before 3.1; it is a bounded UI slice, not the complete demo roadmap. Built directly from main `dfd377f`; it does not depend on another unmerged code branch.

## What changed

- Start with editing and command panels closed, retaining the synthetic mouth, selected tooth and paused state. No scenario, geometry, calculation or teaching content changes.
- Replace the permanent seven-button rail and expanded header actions with Library, Tools, Present and More. More contains open/save, settings, theme, guide, selection and layers. Brand no longer reloads and loses the workspace.
- Group camera presets, arches, before/after/overlay, measurement, focus/isolation, pointer and PNG under View. Keep Fit visible. Retain current-case context, path warnings, lesson ribbons and restore routes outside this menu.
- Give the model the full available width. Tools and Selection/Layers open as scrollable overlays on desktop and retain the existing mobile sheets. Closing one does not remount the model or clear edits.
- Collapse Commands on demand without unmounting the draft input. `/` reveals and focuses it; guide examples do the same. Closed status retains live capture, analysis and errors, with Stop during active work or playback. Local case errors remain visible separately.
- Keep one Undo/Redo pair below the case model; remove the inspector and command-bar duplicates. The separate workflow classroom retains its existing command controls.
- Keep Apply/Discard/Modify independent of hidden panels. Opening Modify restores the tools. Tool visibility derives from the active panel, preventing a closed mobile sheet from leaving editing handles active. Closing tools suspends manipulation/measurement and restores them when reopened.
- Keep one general education line on the desktop opening. Retain context-specific preview, unrestricted, imported-case, root and mechanics labels.
- Native disclosure menus close on outside clicks/Escape, preserve normal keyboard behavior and retain global Escape cancellation. Space on a summary no longer starts voice capture.

## Files and decisions

`Studio.tsx` remains the orchestrator and shrinks. `CaseTopbar` now has explicit callbacks; `CaseWorkspaceHeading`, `CaseArchToolbar` and new `CaseViewControls` use narrowed surfaces. `OpeningCommandDock` owns the collapsed presentation, and `useDisclosureMenu` shares dismissal behavior. Scoped `lecture-opening.css` preserves the existing workflow classroom styles. Layout state has one active-panel source of truth.

Updated the UI and professor guides and the product-direction status note in the same PR. The whole-case API narrowing follow-up remains open: other compositional views and inspectors still use it. The broader CSS deduplication and `try-mode.ts` split are deferred; neither is needed to implement this UI slice. No AGENTS.md, lockfiles, model assets, backend, solver or auditor-owned STATUS changes.
