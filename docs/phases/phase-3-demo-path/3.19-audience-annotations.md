# 3.19 — Public model annotations in the audience view

**Branch:** `ahmed/phase-3-audience-annotations` · **Base:** draft PR #18 at `0b2d126` · **Date:** 2026-09-28 · **Status:** implemented; automated verification passed · **PR:** [#19 (draft)](https://github.com/ahmedgahalla/forma-teaching-studio/pull/19)

## Evidence and intended outcome

The previous goal turn made progress: PR #18 added lecture input/control parity and passed all automated local checks. Its [requirements review](../../reviews/from-builder/2026-09-28-lecture-control-gaps.md) identified the next concrete gap: the audience connection shares the WebGL canvas, while tooth numbers, anatomy/study labels and the lecture pointer are DOM overlays. Students therefore lose those teaching cues. A question detour also loses the public mechanics magnification and arrow qualifications.

This slice carries the public model cues alongside the existing video, without a second renderer or a copy of the presenter's DOM. It retains the sample lecture and single model workspace; it adds no lecture authoring, backend authority or new dental content.

## Design and boundaries

- Viewer label helpers expose fixed reusable slots containing public IDs/text, projected CSS coordinates and visibility. Presenter labels and audience data share each projection/collision decision. Editing lock text is excluded from public tooth labels.
- A canvas-keyed feed has separate staging and committed storage. Only a successfully rendered frame commits positions; pointer events and popup resizes cannot expose unfinished placements. Failure, disposal and source replacement clear the old frame.
- The audience maps source CSS coordinates into the current video's contained rectangle, including letterboxing and drawing-buffer rounding. It does not multiply coordinates by DPR. Pooled DOM/SVG nodes update imperatively; no React state or allocated frame messages are used per render.
- The lecture pointer maps client positions against the actual canvas, and hides on leave, cancellation, blur, Escape, disable, unmount or source-size changes. A replacement source requires a fresh pointer event.
- Anatomy/study captions remain public. Mechanics magnitude is forwarded only with a revealed, current result and no pending preview; hidden calculations retain only their prediction prompt. Schematic arrows and display-only jaw separation retain their public qualifications. Notes, command fields, appliance names and private runtime objects are excluded.
- Canvas observation remains limited to known direct parents. A replacement host that is temporarily empty must also be observed, so a later canvas insertion can reconnect.

This is a spatially mapped sidecar to a 24fps capture stream, not an exact frame synchronization protocol. Browser video latency can cause temporary registration differences during motion. Real orbit/playback and projector acceptance must check this; if that evidence requires exact compositing, it remains a further implementation decision.
