## Scope and source

The owner asked to bring over Claude's open/close jaw option and glowing tooth selection. The source is the existing user-authorized Claude Dentition Atlas workspace `scratch-2026-09-26-716563`. Its `web/src/app/model.js` rotates the lower jaw around the authored hinge; `materials.js` provides an additive Fresnel selection overlay. These files were inspected read-only. The bundled geometry and metadata are unchanged.

The current Atlas metadata supplies hinge `[0, 39.2, -77.8]`, axis `[1, 0, 0]` and maximum opening 14°. The selection overlay uses source color `0x8fc3e0`, base brightness `0.02` and rim brightness `0.6`; it adds light over the original tooth surface. This replaces the previous screen-space blue/teal outline while preserving enamel and root materials.

## Behavior

- **Explore → Display** and **Lecture → View** each offer one context-appropriate **Open jaw / Close jaw** button. Typing or speaking `open jaw`, `close jaw`, `open the mouth` or `shut the mouth` uses the same local validated action, including when AI interpretation is preferred.
- Jaw opening is a display-only 14° hinge for the Atlas mouth. The existing **Separate arches** slider retains its independent millimetre spacing. Source tooth poses, solver inputs/results, tooth locks and mesh buffers are unchanged.
- Lower crowns, roots, ghosts, attachments, gingiva, wires, retainers, TADs, elastic endpoints, force arrows, movement paths and reference curves share the hinge. Gum following first removes the rigid display transform, deforms in the existing case frame, then displays the gum under the hinge once. Upper anatomy remains fixed.
- Camera fit includes the opened lower jaw and gingiva. Picking, surface targets and gizmo commits remove the display transform before creating case-space positions, preventing opening from becoming a tooth edit. Existing camera movement remains; the jaw itself changes between two deterministic poses. Claude's separate 650 ms jaw tween and arbitrary-angle slider were not imported.
- Jaw state participates in request Undo/Redo, workspace/lesson snapshots, lecture question detours and saved lecture setup. Old saves default closed. Authored lecture steps restore their authored closed state unless explicitly saved otherwise. Unsupported models, schematic workflows and isolated tooth study reject the control.
- Selection glow follows selected crown/root geometry, supports multiselection, respects hidden arches/root visibility and is hidden during isolated inspection. It reuses geometry and one material, cannot intercept picking, and requires no bloom/render target or per-frame allocation.

## Implementation boundaries

`jaw-opening.ts` caches the source hinge math; `viewer/jaw-display.ts` owns inverse picking/edit conversion and reference-curve placement. Existing geometry display helpers receive an optional `jawOpen` value. Directly affected anatomy clipping helpers move into `teaching-anatomy-display.ts` so the existing oversized file shrinks. Studio reuses its existing display-state bundle rather than duplicating every field; no new size exception is introduced.

The jaw action is local-only. It and its capability/state fields are excluded from the external AI contract. Backend credentials, provider activation and the completed pitch video are unchanged; the earlier provider-choice question remains pending.
