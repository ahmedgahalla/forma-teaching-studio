## Goal and before/after

The owner requested one learning experience with minimal explanation, more space for the teeth and additional appliance teaching, specifically TADs. This request supersedes the visible professor/student split from earlier phases.

- Lecture now fills the model workspace. The side inspector, teaching sidebar and mobile tool dock are absent during a prepared walkthrough. One short takeaway follows the model and its single playback/calculation control; explanation no longer competes for a side column. Short windows scroll separate rows instead of overlapping the model and text.
- Previous/Next, a named step selector and step count remain visible. Review notes, Present, answer reveal, presenter notes and audience launch are removed from the normal lecture UI. Optional focus, comparison and biology tools live under Inspect and compare. Camera, roots, Fit and the return from exploration remain available.
- All four demos have self-contained takeaways of at most 30 words. Voice narration and AI explanation use this same visible takeaway; comparisons omit it until the original step returns. Historical reference notes and legacy command aliases remain compatible but are not displayed as a second role-specific experience.
- The featured Appliances and tooth movement case now has seventeen steps. Its existing bands, expander, brackets, wire and retention story includes three optional TAD stages: inspect the anchor, connect a passive elastic, then calculate an activated elastic response. The optional example does not imply every case needs a TAD or that the illustrated placement is clinically suitable.
- Activated mechanics steps have Calculate response directly below the model. This runs the existing validated mechanics action and worker; a real result enables the existing playback bar. Passive steps, comparisons, compound edit requests and unrelated edits do not gain this permission. Whole-request Undo/Redo, cancellation and exact step/scene returns remain intact.
- Camera fitting includes visible TAD hardware using the same anatomical owner and lower-jaw transform as rendering. The old tooth-only fit clipped the actual screw on wide views (projected vertical coordinate 1.799 at aspect 3:1, outside the visible -1 to 1 range). Pure projection tests now fit the actual screw, wire and elastic vertices at aspect ratios 3:1, 2:1, 1.5:1 and 0.65:1. Viewer stays at its existing 1,129 lines.
- TADs have a recognizable head, collar and threaded body, using pooled shared geometry. The existing mechanics example is easier to find as Tooth anchorage vs TAD / TAD and elastic; previous typed/voice labels remain aliases.

## Implementation and boundaries

CaseShell and CaseMain own the single workspace, while the lecture-builder components supply compact navigation and the caption. `lecture-mechanics.ts` identifies the single allowed calculation; the session decorator still calls normal preflight. The same caption source feeds `lecture-analysis.ts` and narration. `sample-tad-learning.ts` keeps the new appliance scenes and teaching content as data. `mechanics-tad-view.ts` owns reusable screw geometry and disposal.

The TAD remains fixed while the elastic loads the tooth attachment. Its displayed offset is schematic. The prepared force is a bounded software input, not a clinical force recommendation; the result is an initial elastic response, not biological progression or a predicted treatment endpoint. Authored finishing stages remain independent of either mechanics experiment. Faculty review is pending.

No new top-level mode, lecture creator, arbitrary treatment generator, model asset, AI provider setting or backend behavior is introduced. Existing audience utilities and their independent privacy tests remain, but the normal Lecture workspace no longer starts or exposes a separate audience view. Broader CSS, case-prop and try-mode inbox items remain open. AGENTS.md and auditor-owned STATUS.md are unchanged.
