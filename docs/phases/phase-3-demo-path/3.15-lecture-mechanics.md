The owner authorized the six suggested lecture improvements and additional tooth mechanics, with dentistry research first. No new solver, biological movement predictor, treatment timing, patient-specific appliance prescription or lecture editor is added.

Research is recorded with primary sources and applicability limits in [orthodontic mechanics](../../research/2026-09-27-orthodontic-mechanics.md) and [orthodontic biology](../../research/2026-09-27-orthodontic-biology.md). Compression and tension do not form a universal opposite-sided live stress map on every tooth.

## Teacher experience

1. **Lecture focus:** the selected teaching tooth and roots receive a closer camera fit; surrounding crowns and roots fade while remaining visible. Show surrounding teeth restores context. Focus is off in free Explore. User camera changes survive A/B comparison.
2. **Quick comparison:** Start, Translation and Tipping show absolute endpoints from one camera. Closing comparison restores the exact paused lecture frame; it does not restart the demonstration. Undo/replay and Explore/Return preserve the independent comparison return point.
3. **Less chrome:** one lecture step counter and one step title; selection, axis and duplicate stage/root badges disappear in the lecture view. Preview decisions, voice feedback and errors stay available.
4. **Audience window:** a teacher-operated popup mirrors only the 3D canvas plus explicitly supplied lecture title, step, question, revealed answer and optional biology. Notes and command UI stay in the teacher window. Present only the audience window or put it on an extended display; mirroring the entire desktop still exposes the teacher's screen. The audience cannot manipulate the model. Q&A canvas manipulator handles can be visible because it is the same live canvas.
5. **Tissue explanation:** an optional illustrated panel compares local compression/resorption and tension/formation, with osteoclasts, osteoblasts, enlarged PDL, labels/patterns and source links. These are independent tissue vignettes, not computed stress regions or a simulation of elapsed remodeling. The audience receives the same explanation without interactive links.
6. **Local demo assets:** DM Sans and Manrope are bundled with their original OFL notices; a local favicon and a build-asset check remove the Google Fonts dependency. `npm run demo` builds, checks assets and starts the local server. After a successful build, `npm start -- --open` can serve the static app without rebuilding. Optional AI and browser speech recognition can still require a network.

All model/display commands use the validated runtime. A new request pauses active playback consistently with existing controls. Opening a diagram does not alter tooth transforms or discard a preview. Navigation clears biology and comparison; an explicit question detour restores their saved display state.

Analyze now receives the current lecture step, public question, actual comparison label and explicitly revealed answer through the existing contract. Static steps no longer lose lecture context and Reveal no longer leaves Analyze with the old hidden-answer flag. Presenter notes and unrevealed answers are excluded; Explore and actual scene/calculation facts retain their existing projection.

## Mechanics collection in Explore

Open **Tools → Mechanics examples**, choose a setup and its variation, ask the displayed prediction question, then choose **Load and calculate**. A recipe and its checked response replace the current experiment as one undoable request. The existing Predict before reveal setting can keep calculated results hidden. Change one variation at a time from the same unloaded reference, or edit inputs with the existing mechanics controls. A partway geometric stage must first be moved to Show after; pending previews, locked targets, uncalibrated/imported geometry and incompatible lesson states are rejected before mutation.

| Category                 | Variations                                                              | Teaching point                                                |
| ------------------------ | ----------------------------------------------------------------------- | ------------------------------------------------------------- |
| Crown pull               | Buccal / lingual                                                        | A crown force also creates a turning moment                   |
| Pull with counter-couple | Balanced / half                                                         | Change net moment without changing the pull                   |
| Axial rotation couple    | First / reverse direction                                               | Equal opposite forces can create a rotational couple          |
| Buccolingual inclination | First / reverse direction                                               | Change the couple plane and rotation axis                     |
| Vertical loading         | Intrusion / extrusion                                                   | Reverse the load along the selected tooth's long axis         |
| Molar intrusion balance  | One side / both sides                                                   | Compare load location at the same total load                  |
| Anchorage                | Reciprocal tooth / fixed anchor                                         | Compare reciprocal response with an ideal fixed support       |
| Rectangular wire         | 0.017 × 0.025 steel / 0.019 × 0.025 steel / 0.019 × 0.025 beta titanium | Compare ideal slot play and stiffness at the same total twist |

These eight categories provide 17 variants. Values are authored inputs for this synthetic engineering rig, not recommended clinical forces. Counter-couple balance uses this rig's reference point; there is no universal clinical moment-to-force ratio. The fixed anchor is an ideal graphic support, not an assessed surgical location. Existing solver bounds, worker validation, crossing checks and locks remain in force.

Typing and recognized local speech use the same explicit catalog actions. Lecture examples include `compare translation`, `compare tipping`, `compare start`, `close comparison`, `focus teaching tooth`, `show surrounding teeth`, `show biology`, `show compression`, `show tension` and `hide biology`. In Explore, the mechanics panel provides each exact example command. There is no new backend command authority.
