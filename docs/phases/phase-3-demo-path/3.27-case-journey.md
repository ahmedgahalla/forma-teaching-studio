## Movement, inputs and display boundaries

- One reference model and cumulative absolute poses throughout. Three optional `motion.from` records animate expansion, alignment and finishing through the existing deterministic stage engine. Replay, reverse, seek and revisiting a step do not accumulate poses.
- Installation/removal, reassessment and retention do not move teeth. The upper posterior width remains corrected while anterior alignment finishes; the lower case poses stay unchanged.
- Initial lateral incisors are displayed forward/outward and rotated. Expansion ends at the reference posterior positions; later stages return the incisors toward the reference. These authored coordinates are visual teaching choices, not force prescriptions or calculated biological treatment.
- Opening uses the Atlas jaw hinge to separate the arches for inspection. It does not demonstrate biting contacts. Final closed reference poses are retained; no clinical occlusion or tissue-clearance validation is claimed.
- The wire experiment uses a 0.35 mm steel round wire with a 0.15 mm authored width input, solely as a software experiment. Static review uses a rendered 0.635 x 0.432 mm rectangular profile. These are not clinical appliance recommendations.
- Mechanics inputs are explicit per static step. Explore rebuilds them at the physical displayed poses, discards prior numerical results/stages, and exposes the Appliances panel. It never rebases from magnified display geometry. Return restores the exact paused lecture.
- Authored motion cannot coexist with a mechanics experiment or another case demonstration. Strict validation checks poses, source identity and a unique start/finish comparison pair. Comparison keeps the camera, uses the same open-jaw pose for both endpoints, and restores the paused state on close.
- Retention is the existing bonded anterior lingual wire/pad illustration. The notes distinguish this from a separately assessed plan for posterior/transverse retention. No removable-retainer claim or new appliance renderer is added.
